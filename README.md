# Lâmpada On/Off

Projeto de estudo em **HTML**, **CSS** e **JavaScript** que simula ligar e desligar uma lâmpada ao clicar na imagem.

## Sobre o projeto

Exercício simples de interatividade na web: ao clicar na lâmpada, a imagem alterna entre apagada e acesa, e o fundo da página muda para simular luz acesa ou ambiente escuro.

## Funcionalidades

- Clique na lâmpada para ligar e desligar
- Troca de imagem (`lamp_off` / `lamp_on`)
- Alteração do fundo com gradiente radial (claro ou escuro)
- Uso de eventos de clique no DOM

## Tecnologias

- HTML5
- CSS3
- JavaScript (Vanilla)
